# ⚽ สรุปโปรเจค PremierPredict-AI (SEA612) สำหรับแก๊งเรา

หวัดดีเพื่อนๆ! นี่คือสรุปสั้นๆ ว่าพวกเราทำอะไรกันไปบ้างในโปรเจค **SEA612: AI Presentation** จะได้เอาไปคุยหรือตอบอาจารย์ได้แบบเนียนๆ นะ

---

### 🎯 เป้าหมายของโปรเจค (Goal)
เราต้องการสร้าง **AI ที่ทายผลบอลพรีเมียร์ลีกได้แม่นกว่าคน!** 
- ปัญหาเดิมคือคนมักจะทายตามความชอบส่วนตัว (Bias) หรือดูแค่สถิติผิวเผิน 
- เราเลยสร้างระบบที่รวมเอาทั้ง **คะแนนความเก่ง (ELO)**, **มูลค่านักเตะ (Transfermarkt)** และ **ฟอร์มการเล่น** มาคำนวณแบบไม่มีอคติ

### 👥 บทบาทของพวกเรา (Roles)
*(อันนี้แบ่งตามเนื้องานที่ทำจริง เพื่อนๆ ปรับเปลี่ยนได้นะ)*
1. **ชัยพร (Chaiyaporn):** หัวหน้าทีม, ทำระบบ Data Engineering และทำ Dashboard UI (Streamlit) ให้กดดูง่ายๆ
2. **กฤติน (Krittin):** เซียน AI, ออกแบบและจูนโมเดล Stacking Ensemble (พระเอกของงาน) ให้แม่นยำที่สุด
3. **ปวรวิชญ์ (Pawornwit):** ฝ่ายวิจัยและเก็บข้อมูล, รวบรวมสถิติจาก FPL และ BBC มาเปรียบเทียบ (Benchmark) และทำรายงาน

### 🛠️ วิธีการดำเนินงาน (How we did it)
พวกเราไม่ได้ใช้แค่โมเดลเดียวทาย แต่เราใช้ **"Stacking Ensemble"** (การทำงานแบบเป็นทีมของ AI):
1. **เก็บข้อมูล:** ดึงข้อมูล ELO, ราคาตลาดนักเตะ, และฟอร์ม 5 นัดล่าสุดมา
2. **สร้างกองทัพ AI (Layer 1):** ใช้ XGBoost, Random Forest, และ Gradient Boost มาช่วยกันทายคนละไม้คนละมือ
3. **ตัวตัดสิน (Layer 2):** ใช้ Logistic Regression มาเป็นกรรมการตัดสินว่าควรเชื่อโมเดลไหนมากที่สุดในแต่ละแมตช์
4. **วัดดวง:** เอาผล AI ไปแข่งกับ "ความแม่นของแฟนบอล FPL" และ "กูรู BBC"

### 🏆 ผลการทดลองเราเทพแค่ไหน? (Results)
ผลออกมาคือ **AI เราชนะขาดลอย!**
- **AI ของเรา (V5.0):** แม่นยำ **55.3%**
- **แฟนบอล FPL (คนทั่วไป):** แม่นยำ **54.7%**
- **กูรูจาก BBC (มือโปร):** แม่นยำ **47.1%**
*สรุปคือ AI เราฉลาดกว่าทั้งคนทั่วไปและผู้เชี่ยวชาญไปแล้วครับเพื่อน!*

### 📅 แผนการทำงาน (Timeline)
- **สัปดาห์ 1-2:** หาข้อมูลสถิติและคะแนน ELO (Data Scraping)
- **สัปดาห์ 3-4:** ลองรันโมเดลเดี่ยวๆ (V1.0 - V3.0) แต่ยังไม่ค่อยแม่น
- **สัปดาห์ 5:** พัฒนาระบบ Stacking Ensemble (V5.0) จนได้ความแม่นสูงสุด
- **สัปดาห์ 6 (ปัจจุบัน):** ทำ Dashboard ภาษาไทย และเตรียมสไลด์นำเสนอสุดเทพ
